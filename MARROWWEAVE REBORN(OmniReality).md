## 1. Introduction & Overview

PDLab is an open‑source, multi‑paradigm research and experimentation platform that implements over 350 public‑domain mathematical, physical, biological, and computational models. It provides simulation, optimisation, experiment tracking, and interactive exploration through multiple interfaces.

**Core Capabilities**  
- Unified model definitions using Pydantic V2 with automatic schema extraction.  
- Three simulation engines: continuous (ODE/DAE), discrete‑event (SimPy), and Monte Carlo.  
- Optimisation via Optuna (with TPE, NSGA‑II) and SciPy (differential evolution, gradient‑based).  
- Experiment management: local JSON storage and cloud‑aware Delta Lake (S3).  
- Interfaces: Textual TUI, Streamlit dashboard, FastAPI RESTful API, Click CLI.  
- Production‑ready deployment: Docker, Kubernetes Helm charts, Celery workers, Prometheus/Grafana monitoring.

**Design Principles**  
- **Modularity:** Each domain and engine is a separate Python package.  
- **Immutability:** Core models are frozen to ensure side‑effect‑free simulations.  
- **Extensibility:** Adding a new model requires only subclassing `LabModel` and optionally registering a simulation handler.  
- **Polyglot Persistence:** Use local JSON for developer mode, Delta Lake for production.  
- **Async‑First:** Web API and UI are asynchronous; CPU‑bound tasks are offloaded to Celery workers.

### 3.1 Base Class: `LabModel`

```python
from pydantic import BaseModel, Field, ConfigDict, model_validator
from typing import Optional, Dict, Any
import uuid
from datetime import datetime

class LabModel(BaseModel):
    model_config = ConfigDict(arbitrary_types_allowed=True, frozen=True, validate_assignment=True)
    id: str = Field(default_factory=lambda: str(uuid.uuid4()))
    created_at: datetime = Field(default_factory=datetime.utcnow)
    updated_at: datetime = Field(default_factory=datetime.utcnow)
    metadata: Dict[str, Any] = Field(default_factory=dict)

    @model_validator(mode="after")
    def update_timestamp(self):
        self.updated_at = datetime.utcnow()
        return self
```

## 4. Simulation Engines (pdlab.core.engines)

### 4.1 Abstract Base Class
```python
class SimulationEngine(ABC):
    @abstractmethod
    def setup(self, model: LabModel, params: Dict) -> None: ...
    @abstractmethod
    def step(self, dt: float) -> Dict[str, Any]: ...
    @abstractmethod
    def get_state(self) -> xr.Dataset: ...
```

### 4.2 Implementations

#### `ContinuousEngine`
- Uses `scipy.integrate.solve_ivp` with adaptive time stepping.
- Accepts ODE function derived from model’s equations.
- Stores state as `xarray.Dataset` with coordinates `time` and variable names.
- `step(dt)` advances simulation by `dt` (fixed or adaptive) and returns a dict of current outputs.

#### `DiscreteEventEngine`
- Built on `simpy.Environment`.
- `setup()` creates processes from model definition (e.g., queueing networks, Geneva drive).
- `step(dt)` runs the simulation for `dt` time units, returns events processed.

#### `MonteCarloEngine`
- Samples parameter distributions (from model’s uncertainty metadata) using numpy.
- Runs `N` independent simulations and returns summary statistics (mean, std, percentiles).

#### `PINNEngine` (stub)
- Planned: use PyTorch or JAX to train a neural network surrogate.
- `setup()` loads a pre‑trained model or trains on‑the‑fly.

### 4.3 Simulation Dispatcher (pdlab.core.simulations)
**Function:** `run_simulation(model_name: str, params: Dict) -> Dict[str, Any]`  
- Imports the model class from `core.models` dynamically.  
- Instantiates the model.  
- Selects engine based on model’s `simulation_engine` metadata (default: Continuous).  
- Runs the simulation for a default time span (or uses parameters).  
- Returns a dictionary containing results: scalars, time‑series arrays, or nested structures.  
- All results are serializable to JSON.

## 10. Security

### 10.1 Authentication Flow
1. Client sends `username`/`password` to `/token`.
2. Server validates against DB (bcrypt‑hashed passwords).
3. Returns JWT with `sub` (username) and expiry.
4. Subsequent requests include `Authorization: Bearer <token>`.
5. Protected endpoints call `Depends(get_current_user)` which decodes JWT and fetches user from DB.

### 10.2 Authorisation
- Experiment CRUD endpoints check that the requesting user owns the experiment.
- No admin roles needed; all users are equal.

### 10.3 Data Security
- All API communication should be over HTTPS (production).
- Passwords never logged.
- Sensitive environment variables not stored in code; use `.env` or Kubernetes secrets.

## 13. Extensibility – How to Add a New Model

1. **Define a new class** in `pdlab.core.models` (or in a domain submodule, then import into `core/models.py`).
   - Inherit from `LabModel`.
   - Add typed fields with `Field` constraints.
   - Optionally define methods (e.g., `delta_v`).
2. **Optionally provide a simulation function** in `pdlab.core.simulations` and register it in `SIMULATION_MAP` if the default engine is insufficient.
3. **Automatic discovery** – the model will appear in the list of available models (via `get_available_models()`).
4. **UI** – the TUI and Streamlit will automatically generate parameter inputs based on the schema.
5. **Optimisation** – the Optimizer will automatically build parameter spaces from the schema.

**Example:** Adding a new `FourierHeatConduction` model requires only writing the class; no UI changes.
